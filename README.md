# Liquid Glass TV — кастомный лончер для Android TV

Полноценное приложение-лончер с дизайном в духе "Liquid Glass":
полупрозрачные стеклянные карточки, мягкое свечение на фоне, блюр.
Показывает сетку установленных TV-приложений и запускает их.

## Как собрать APK — БЕЗ установки чего-либо на компьютер

Сборка делается на серверах GitHub (бесплатно). Вам нужен только
аккаунт на github.com — ничего скачивать и ставить не придётся.

### Шаг 1 — создать репозиторий
1. Зарегистрируйтесь / войдите на https://github.com
2. Нажмите **+** → **New repository**
3. Назовите, например, `LiquidGlassTV` → Create repository
   (можно Private — не важно)

### Шаг 2 — залить код
На странице репозитория нажмите **"uploading an existing file"**
(или "Add file" → "Upload files") и перетащите туда **всё
содержимое** папки `LiquidGlassTV` из этого архива (включая
скрытую папку `.github` — если её не видно в проводнике,
включите показ скрытых файлов).

Затем внизу страницы нажмите **Commit changes**.

### Шаг 3 — запустить сборку
1. Откройте вкладку **Actions** вверху репозитория
2. Слева выберите workflow **"Build APK"**
3. Справа нажмите **Run workflow → Run workflow**
4. Подождите 3–5 минут (статус станет зелёной галочкой ✅)

### Шаг 4 — скачать готовый APK
Откройте завершившийся запуск → внизу страницы раздел
**Artifacts** → скачайте **LiquidGlassTV-debug-apk**
(это zip с готовым `app-debug.apk` внутри).

Дальше — как обычно: закинуть APK на ТВ через ADB или флешку.

## Как установить на телевизор

Вариант А — через ADB (см. предыдущий скрипт):
```
adb connect <IP_ТВ>:5555
adb install -r app-debug.apk
```

Вариант Б — закинуть APK на флешку / в облако и открыть файловым
менеджером прямо на ТВ.

## Как сделать лончером по умолчанию

Настройки → Приложения → Главный экран по умолчанию →
выбрать **Liquid Glass TV**

## Что можно донастроить под себя

Все цвета и стиль "стекла" — в файле:
`app/src/main/java/com/liquidglass/tv/ui/theme/GlassTheme.kt`

- `backgroundGradient` — цвета фонового градиента
- `GlassSurface` / `GlassSurfaceFocused` — прозрачность карточек
- в `MainActivity.kt`, функция `GlassBlob` — размер и яркость
  светящихся пятен на фоне

## Откат обратно

Настройки → Приложения → Главный экран по умолчанию → выбрать
обратно стандартный Android TV Home, либо просто удалить
Liquid Glass TV как обычное приложение.
